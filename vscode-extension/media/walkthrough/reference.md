# Reference Architectures

Start from a proven Microsoft reference architecture template instead of building from scratch.

## Available templates (16)

- **Web App** — App Service + SQL + Redis + Front Door
- **Microservices** — AKS + Service Bus + Cosmos DB
- **AI Landing Zone** — OpenAI + APIM + Private Endpoints
- **Hub-Spoke Network** — Firewall + VNet peering + Bastion
- **Event-Driven** — Functions + Event Grid + Storage
- **Data Platform** — Synapse + Data Lake + Data Factory
- **IoT Solution** — IoT Hub + Stream Analytics + Cosmos DB
- And more...

## How to use

1. Run **Azure Visio: Load Reference Architecture** from the command palette
2. Pick a template from the list
3. The template is applied to your current diagram
4. Customize resources and connections as needed

You can also ask:
```
@azureVisio /reference microservices
```
