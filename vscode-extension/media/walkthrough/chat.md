# Chat with @azureVisio

The `@azureVisio` chat participant turns natural language into Azure architecture diagrams.

## How it works

1. Open **Copilot Chat** (`Ctrl+Shift+I`)
2. Type `@azureVisio` followed by what you want to build
3. Watch as resources, connections, and boundaries appear in your diagram

## Example prompts

```
@azureVisio draw a 3-tier web app with App Service, SQL Database, and Redis Cache
```

```
@azureVisio draw a microservices architecture with AKS, Service Bus, and Cosmos DB
```

```
@azureVisio draw an AI landing zone with OpenAI, API Management, and private networking
```

## Slash commands

| Command | Description |
|---------|-------------|
| `/draw` | Create a new diagram from a description |
| `/validate` | Run WAF/CAF validation |
| `/sku` | Get pricing & SKU guidance |
| `/save` | Export to .vsdx or .drawio |
| `/reference` | Load a reference architecture |
